# 六国互联网普及率变化分析

## 一、项目背景

本项目使用 Python 获取世界银行公开数据，对中国、美国、日本、德国、印度和巴西的互联网普及率进行清洗、统计和可视化分析。

## 二、数据来源

- 数据提供方：世界银行
- 获取方式：World Bank API
- 指标代码：IT.NET.USER.ZS
- 指标含义：使用互联网的人口比例

## 三、技术工具

- Python：项目主要编程语言
- Requests：获取 API 数据
- Pandas：数据清洗、整理和统计
- Matplotlib：生成数据可视化图表

## 四、分析流程

1. 调用公开 API，获取六国年度数据。
2. 将 JSON 数据整理并保存为原始 CSV。
3. 处理字段类型、缺失值、重复值和异常范围。
4. 筛选六国都有数据的共同年份，统一比较口径。
5. 计算最新共同年份的国家差异及统计期间内的增幅。
6. 生成趋势图、国家对比图和增幅图。
7. 输出数据结论与分析限制。

## 五、主要结论

## 六、分析限制

本项目仅比较六个国家的年度总体指标，不能反映各国内部城乡、年龄和收入群体之间的差异，也不根据相关性直接推断因果。
